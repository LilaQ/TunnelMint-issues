# TunnelMint support

This is the public support, issue-tracking, privacy, and security-information repository for **TunnelMint**, a multi-protocol VPN client for macOS.

TunnelMint is a VPN client, not a VPN service. It connects to compatible servers and configurations supplied by you, your organization, or your VPN provider.
