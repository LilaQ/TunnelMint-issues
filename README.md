# TunnelMint support

This is the public support, issue-tracking, privacy, and security-information repository for **TunnelMint**, a multi-protocol VPN client for macOS.

TunnelMint is a VPN client, not a VPN service. It connects to compatible servers and configurations supplied by you, your organization, or your VPN provider.

## Get help

- [Report a bug](https://github.com/LilaQ/TunnelMint-issues/issues/new?template=bug_report.yml)
- [Request a feature](https://github.com/LilaQ/TunnelMint-issues/issues/new?template=feature_request.yml)
- [Read the support guide](SUPPORT.md)
- [Privacy information](PRIVACY.md)
- [Security reporting](SECURITY.md)
- [Third-party notices](THIRD_PARTY_NOTICES.md)

Never post VPN passwords, private keys, certificates, complete configuration files, recovery codes, company-internal hostnames, private IP addresses, or unredacted logs in a public issue.

## Release status

TunnelMint is under active development and has not completed its commercial release review. Seller identity, regional availability, private support contact, and App Store declarations still require owner and legal approval before distribution.

This repository contains public product documentation only. No source-code license is granted here.
