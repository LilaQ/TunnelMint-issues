# TunnelMint support guide

## Before opening an issue

1. Confirm the VPN profile still works with another known-compatible client or with your organization's documented setup.
2. Record the TunnelMint version and build number from **Settings → Legal & Compliance**.
3. Note the macOS version, Mac model, protocol, authentication type, and imported file format.
4. Remove all credentials, keys, certificates, tokens, internal hostnames, private addresses, and personal data from anything you plan to share.

## Contact support

Use a [bug report](https://github.com/LilaQ/TunnelMint-issues/issues/new?template=bug_report.yml) for reproducible failures and a [feature request](https://github.com/LilaQ/TunnelMint-issues/issues/new?template=feature_request.yml) for new protocol, import, authentication, or workflow ideas.

This public tracker is not suitable for confidential enterprise configurations or security vulnerabilities. Follow [SECURITY.md](SECURITY.md) for security reports.

Any publisher, address, email, or telephone details legally required for a particular storefront or territory are provided in the applicable store listing.
