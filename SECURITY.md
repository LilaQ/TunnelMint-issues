# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability and do not attach secrets, private keys, certificates, VPN configurations, or exploit details to a public ticket.

Use GitHub's private vulnerability-reporting flow for this repository when available. Include the affected TunnelMint version, macOS version, protocol/engine, impact, reproduction steps, and a minimal redacted proof of concept.

Release blocker: the owner must approve a monitored private security contact and response policy before commercial distribution.

## Supported versions

TunnelMint is currently pre-release. A supported-version table and security-update policy will be published before the first commercial release.
